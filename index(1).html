Catalog Rules

These control how far a card jumps forward each time you review it.

Revision intervals

Days-until-next-review at each stage. A card advances one stage per successful review; it resets to stage 1 if you mark it "Forgot."

Default: 1 → 3 → 7 → 14 → 30 → 90 days. This is a classic spaced-repetition ramp — feel free to tune it.

Sync via GitHub

Store your cards as a JSON file in a GitHub repo so any device that opens this page can pull the same data. This turns the repo into your database — no separate server needed.

Use a fine-grained token scoped to only this repository, with Contents: Read and write permission, and an expiry date. Create one at github.com → Settings → Developer settings → Fine-grained tokens. The token is saved only in this browser's local storage — it is never written into the repo or included in JSON exports. Anyone using this page on another device or browser needs to enter their own token.
Not connected.

Backup & transfer

A manual JSON export/import, in addition to or instead of GitHub sync. Useful as a one-off backup or if you'd rather not use a token.

Reset

This clears every card and setting stored in this browser. It cannot be undone — export a backup first.
